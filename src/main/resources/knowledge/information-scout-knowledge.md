# 信息猎手知识手册

本文档用于 Skill RAG 的 information-scout 知识导入示例。内容仅供演示，不包含真实凭据。

## 多源校验规则

1. 核心事实至少需要两个独立来源交叉验证。
2. 若只有一个来源，应标记为“待验证”，不得直接作为高置信推荐。
3. 官方网站、权威媒体、原始数据源的优先级高于二手转载。
4. 当不同来源冲突时，应记录冲突点和更可信的判断依据。

## 推荐理由模板

推荐信息时，建议统一说明：

- 这条信息为什么与主题相关
- 来源是什么、是否可追溯
- 是否经过交叉验证
- 当前可信度等级是什么
- 是否仍需人工进一步确认

示例格式：
> 该信息与主题相关，来源为官方公告，已与媒体报道交叉验证；当前可信度为中高，建议保留并继续跟踪。

## 噪声过滤规则

1. 标题党、夸大表述、无来源传闻应优先降权。
2. 纯营销内容、重复采集内容、无增量信息的内容应过滤。
3. 若文章没有时间、出处或作者信息，应谨慎使用。
4. 与主题只有弱相关的边缘内容，不作为主要推荐。

## 人工审核回流机制

1. 信息猎手的结果不得自动回流知识库。
2. 只有经过人工审核、确认准确且具备长期价值的内容，才允许入库。
3. 审核记录应至少包含：审核人、审核时间、来源、结论和是否放行。
4. 若信息具备时效性，应同时记录有效期或复核周期。

## 信息溯源格式

推荐结果建议保留溯源字段：

- 标题
- 原始链接
- 发布时间
- 来源机构
- 校验状态
- 人工审核状态

这样后续维护时更容易判断内容是否过期或失效。
