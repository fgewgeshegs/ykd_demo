# 旅行规划知识手册

本文档用于 Skill RAG 的 travel-planning 知识导入示例。内容仅供演示，不包含真实凭据。

## 签证与证件

1. 出发前至少提前 30 天确认目的地签证类型、有效期和入境次数。
2. 护照有效期建议比计划离境日期多 6 个月以上。
3. 重要证件建议保留电子扫描件和纸质复印件分开存放。
4. 若目的地需要邀请函、酒店预订单或往返机票证明，建议提前准备模板并核对拼写。

## 预算标准

1. 国内短期出差建议优先选择交通便利、安全评级高的住宿，避免因低价导致通勤和安全风险。
2. 预算应至少覆盖：交通、住宿、餐饮、通讯、保险和不可预见费用。
3. 若行程跨多城市，应单独列出城际交通和本地交通预算。
4. 预算审批前应核对是否符合公司差旅标准，超标需提前说明原因。

## 健康与保险

1. 长途飞行建议准备基础药品、防护用品和必要的疫苗提醒。
2. 出发前确认是否覆盖境外医疗、紧急就医和紧急转运保障。
3. 有慢性病或过敏史的人员，应随身携带必要药物和说明卡。
4. 到达后注意饮水、食物、暴晒和高湿度环境带来的健康风险。

## 时差与通讯

1. 跨时区行程建议提前 2 天逐步调整作息。
2. 重要会议建议预留缓冲时间，避免首日安排高强度任务。
3. 出发前确认通讯方式、漫游方案、备用联系人和紧急通知链路。
4. 若团队跨时区协作，应在文档中明确统一参考时区。

## 紧急联系方式

1. 建议统一维护：当地紧急电话、公司安全联系人、差旅服务联系人和保险报案入口。
2. 紧急联系信息建议同时保存在手机、纸质卡片和共享文档中。
3. 若同行多人，建议指定一位主联系人和一位替补联系人。
4. 示例占位号码：当地急救 000-0000、公司安全联系人 000-0000。

## 出行 Checklist

- [ ] 护照/签证/身份证件
- [ ] 机票、酒店、会议地址
- [ ] 差旅审批与预算说明
- [ ] 保险与医疗信息
- [ ] 通讯方案与紧急联系人
- [ ] 电源转换器、网络和基础药品
